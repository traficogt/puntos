# Archivo editorial

Estos JSON y notas de fuentes conservan los borradores revisados originalmente.
No son el catálogo de publicación ni las vistas previas actuales. Sus ejemplos
pueden ser anteriores a las correcciones editoriales y a la revisión de funciones.

Para editar o reutilizar un artículo, consulta primero `../manifest.json`, que
alimenta tanto las publicaciones como las vistas previas actuales. Conserva aquí
la procedencia y las comprobaciones de fuentes; no conviertas un ejemplo antiguo
en una afirmación de capacidad del producto sin volver a verificarla.

La revisión de los seis artículos, los cambios de ejemplos y las funciones aún
pendientes están documentados en
[`docs/ARTICLE_CAPABILITY_AUDIT_20261116.md`](../../../../docs/ARTICLE_CAPABILITY_AUDIT_20261116.md).
