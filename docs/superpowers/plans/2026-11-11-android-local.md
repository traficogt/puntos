# Local Android builder implementation plan

> Use superpowers:subagent-driven-development for the isolated launcher task, followed by independent spec and correctness reviews. Parent owns the container toolchain, host setup and release evidence.

**Goal:** Produce validated signed Android binaries on PF's Linux VM with no Codemagic/EAS minutes.
**Architecture:** A manual Node launcher copies source into a private workspace and starts a resource-limited Docker toolchain. Existing Expo prebuild/signing/Gradle/binary validators remain authoritative. Caches and credentials stay external to source. No app publishing.
**Tools:** Existing Node test runner, Docker, Expo 57, Java 17, Gradle wrapper, Android SDK 36 and NDK 27.1.

## Tasks

- [x] Launcher: add `apps/customer/scripts/android-local.mjs` and a small testable library if needed, plus `tests/android-local.test.ts`. Public commands: `doctor`, `setup`, `build --version-code 13`. Defaults: state `/var/lib/puntos/android-builder`, image `puntos-android-builder:20261111`, signing files `/var/lib/puntos/credentials/android/pf-upload.p12` and `pf-upload.password`, alias from existing signing manifest supplied as nonsecret config. Inputs are explicit version, optional state/signing paths; fail on unsupported platform, invalid version, insufficient disk/RAM, missing private credentials, symlink secrets/source escape, or concurrent build. Test before implementation with temporary directories and injected Docker runner; no real toolchain downloads in tests. Commands use argument arrays with no shell interpolation. The image build context is `apps/customer/tools/android`, never the whole source tree. Build mounts isolated copied app `/work`, SDK cache `/opt/android-sdk`, Gradle cache `/cache/gradle`, npm cache `/cache/npm`, output `/artifacts`, and secret files `/run/secrets/android-upload.p12` and `/run/secrets/android-password`. Container entrypoint verbs `setup` / `build`; build receives explicit `PF_ANDROID_VERSION_CODE` and `PF_ANDROID_KEY_ALIAS`, never passwords. Apply `--cpus=1 --memory=4g --memory-swap=4g --pids-limit=512 --cap-drop=ALL --security-opt=no-new-privileges`; single-flight lock. Never call cloud/store APIs. Record source/artifact hashes and clean temporary app on completion; preserve diagnostic log on failure.
- [x] Container: add `apps/customer/tools/android/{Dockerfile,entrypoint.sh,.dockerignore}` with pinned official tools/checksums, persistent SDK/cache support, configured Java 17 for Gradle, capped Gradle workers/JVM/Metro and no secret COPY. `setup` accepts required SDK licenses and installs exact SDK packages. `build` runs `npm ci --include=dev --no-audit --no-fund`, lint/typecheck/tests, loads signing material privately, then `bash scripts/build-android-release.sh all`, preserving existing manifest/signature/16 KB checks. Reuse existing artifacts filenames and do not advance app version. Test shell syntax, task-specific entrypoint doubles, SDK/package identity, and private credential cleanup.
- [x] Documentation/config: add `docs/ANDROID_LOCAL.md`, update `docs/ANDROID_RELEASE.md` to point to manual local commands and distinguish prior Codemagic history. Remove only `pf-android-release` from root `codemagic.yaml`; preserve all iOS blocks. Adjust stale workflow assertions if necessary. Record setup/verification status honestly.
- [x] Validation and installation: run app unit/lint/typecheck, review, verify no UI/dependency/version/iOS drift, sync scoped scripts/docs/YAML only. Once disk expansion is available, bootstrap the toolchain then run `node apps/customer/scripts/android-local.mjs build --version-code 13` locally. Validate existing signer and package/version/permissions/alignment, artifact hashes and PF API/worker health. Save evidence in `/var/lib/puntos/releases/android-local-20261111`; report any storage or real-device blocker precisely. Do not publish or trigger cloud jobs.

Verified local signed build and final launcher checks are recorded in `/var/lib/puntos/releases/android-local-20261111/release-report.json`. Dependency upgrade preparation is a separate parallel task; no dependencies were updated here.
