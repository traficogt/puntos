# Guías Implementation Plan

**Goal:** Add an empty Spanish guides section and a safe publication structure without publishing article content.

**Architecture:** A validated, repository-owned JSON catalog feeds one escaped server renderer, an Express middleware, and the existing search visibility middleware. There is no database, CMS, client script, or new dependency. The empty hub is noindex/noarchive; only explicitly published entries become public and enter the sitemap.

**Tech stack:** Existing Node, Express, Zod, HTML/CSS, and Playwright.
