# Descontar saldo de una tarjeta de regalo

Usa el código de la tarjeta de regalo y confirma el importe antes del descuento. (PuntosFieles, 2026).

[Abrir la pantalla de esta tarea](/equipo/escaner/#giftCardActionBlock)

## Antes de empezar

Necesitas conexión y permiso para gift cards. El descuento de una tarjeta de regalo es una operación diferente del canje de puntos.

## Paso a paso

1. En **Gift Cards**, introduce **Código o token** de la tarjeta.
2. Escribe **Monto a descontar** en la moneda del negocio.
3. Confirma el importe con el cliente y pulsa **Canjear gift card** una vez.
4. Espera el resultado y revisa el saldo o mensaje mostrado antes de dar la operación por terminada.

## Qué debe pasar

La pantalla confirma el descuento autorizado. Conserva la referencia con el comprobante de la compra según el procedimiento del negocio.

## Si algo no funciona

**Saldo insuficiente, tarjeta inválida o permiso denegado:** revisa el código y consulta al responsable. **Resultado incierto:** no repitas con otro importe para probar; pide verificar el historial. **Botón no disponible:** revisa conexión, permisos y plan.
