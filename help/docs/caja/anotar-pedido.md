# Anotar una solicitud del cliente

Registra lo que una persona pidió para que el dueño pueda revisar temas repetidos. (PuntosFieles, 2026).

[Abrir la pantalla de esta tarea](/equipo/escaner/)

## Antes de empezar

Usa conexión. Si la solicitud corresponde a un cliente registrado, selecciónalo primero para vincularla a su cuenta.

## Paso a paso

1. En el escáner, busca **Anotar un pedido**.
2. Elige **¿Qué estás pidiendo?** y escribe un **Pedido breve** con el producto o necesidad concreta.
3. Completa la recompensa relacionada, producto o contexto y detalle cuando ayuden a entenderlo.
4. Pulsa **Guardar pedido** y verifica la confirmación.
5. Usa **Actualizar pedidos** para revisar el registro y comunica al cliente que es una solicitud para evaluar.

## Qué debe pasar

Un cliente seleccionado cuenta una vez por tema. Las observaciones del personal se distinguen de las personas únicas; no son ventas perdidas comprobadas.

## Si algo no funciona

**No hay cliente seleccionado:** registra la observación sin inventar una identidad. **El cliente quiere comprar:** atiende la venta por el procedimiento normal; anotar un pedido no crea orden ni reserva.
