# Reportar una recompensa no entregada

Deja un caso cuando el beneficio no pudo entregarse o hubo un problema con el canje. (PuntosFieles, 2026).

[Abrir la pantalla de esta tarea](/equipo/escaner/#staffServiceCases)

## Antes de empezar

Selecciona al cliente y usa conexión. Distingue un intento rechazado, que no descontó puntos, de un canje confirmado con entrega pendiente.

## Paso a paso

1. Abre la sección **Incidencias de servicio** del escáner.
2. Elige **Canje relacionado** cuando el problema corresponde a un canje registrado.
3. Describe **Qué ocurrió** con datos de la operación y sin información personal innecesaria. Pulsa **Registrar incidencia**.
4. Usa **Actualizar casos** y luego **Revisar caso** para comprobar el registro.
5. Si necesitas una decisión del dueño, escribe **Motivo del seguimiento** y pulsa **Escalar al dueño**.

## Qué debe pasar

El caso conserva lo ocurrido para que el responsable lo atienda. Reportarlo no devuelve automáticamente puntos, no cambia existencias y no demuestra una entrega.

## Si algo no funciona

**El caso ya existe:** revísalo en lugar de crear otro por el mismo problema. **No tienes autorización para resolver:** escala al dueño. **Sin conexión:** informa al responsable por el procedimiento del negocio y registra el caso cuando vuelvas a tener internet.
