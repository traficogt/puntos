# Crear mi tarjeta del negocio

Abre el enlace de inscripción del negocio y verifica tu teléfono para obtener tu tarjeta. (PuntosFieles, 2026).

[Abrir la pantalla de esta tarea](/mi-tarjeta/)

## Antes de empezar

Pide el QR o enlace oficial al negocio. Comprueba su nombre antes de escribir tus datos. Necesitas acceso al teléfono y conexión.

## Paso a paso

1. Escanea el QR de inscripción o abre el enlace que te compartió el negocio.
2. Escribe tu **Teléfono** y los datos que solicite el formulario. Para otro país, incluye el prefijo internacional. Si alguien te invitó, revisa **Código de referido (opcional)**: el enlace de invitación ya lo completa; si no tienes código, déjalo vacío.
3. Pulsa **Enviar código**. Revisa el canal y las indicaciones que aparecen en pantalla.
4. Escribe el **Código** recibido y pulsa **Verificar y crear tarjeta**.
5. Cuando aparezca **Tu tarjeta ya está activa**, elige **Ver mi tarjeta y mis puntos** o una opción de Wallet disponible.

## Qué debe pasar

La tarjeta muestra el nombre del negocio. Verificar tu teléfono permite entrar a tu cuenta; la inscripción no garantiza puntos o un premio si el programa no los ofrece.

## Si algo no funciona

**El enlace no identifica un negocio:** pide de nuevo su enlace de inscripción. **No llega el código:** revisa el teléfono y el tiempo indicado antes de **Reenviar código**. **Ya tienes tarjeta:** usa la opción de ingreso para el mismo teléfono; no necesitas crear otra cuenta. **Aparece “Revisa el código de referido”:** el código tiene 6 letras o números; corrígelo o deja vacío **Código de referido (opcional)**. Si el código no existe o el negocio desactivó las recomendaciones, tu tarjeta se crea igual, sin quedar vinculada a quien te invitó.
