# Compartir una idea o un pedido

Dile al negocio qué producto, recompensa o servicio te gustaría encontrar. (PuntosFieles, 2026).

[Abrir la pantalla de esta tarea](/mi-tarjeta/#customerDemand)

## Antes de empezar

Abre tu tarjeta con conexión. Este formulario recoge una solicitud para revisar, no un pedido de compra ni una reserva.

## Paso a paso

1. Busca **¿Qué te gustaría encontrar?**.
2. Elige **¿Qué estás pidiendo?** y escribe un **Pedido breve**.
3. Si corresponde, elige **Recompensa relacionada (opcional)** y agrega producto, contexto o detalle sin datos sensibles.
4. Pulsa **Guardar pedido** y espera la confirmación.
5. Usa **Actualizar pedidos** para consultar el seguimiento disponible.

## Qué debe pasar

Tu solicitud queda registrada para que el negocio la revise. Una solicitud no garantiza disponibilidad ni compromete una compra.

## Si algo no funciona

**No se guardó:** revisa conexión y sesión antes de reintentar. **Necesitas ordenar o reservar ahora:** comunícate directamente con el negocio por sus canales de venta; este registro no reemplaza esa atención.
