# Volver a entrar a mi tarjeta

Recupera el acceso usando el mismo teléfono con el que te registraste en ese negocio. (PuntosFieles, 2026).

[Abrir la pantalla de esta tarea](/mi-tarjeta/)

## Antes de empezar

Necesitas el enlace de acceso del negocio, internet y poder recibir el código temporal. El acceso de clientes es diferente de **Ingreso del equipo**.

## Paso a paso

1. Abre el enlace del negocio. Si ya tienes sesión, abre **Mi tarjeta**.
2. Si pide verificación, escribe tu **Teléfono** y pulsa **Enviar código**.
3. Escribe el código de seis dígitos recibido y pulsa **Verificar y entrar**.
4. Usa **Cambiar teléfono** si escribiste otro número por error; para conservar la cuenta, utiliza el número registrado.
5. Pulsa **Ver mi tarjeta y mis puntos**.

## Qué debe pasar

Vuelves a la cuenta del mismo teléfono y negocio. El nombre de la tarjeta permite comprobar que estás en el programa correcto.

## Si algo no funciona

**Sesión vencida:** vuelve al enlace del negocio y solicita otro código. **Ya no tienes acceso al teléfono:** pide ayuda al negocio; este flujo no cambia el número de una cuenta ni transfiere puntos. Nunca envíes el código temporal a soporte.
