# Elegir si quiero recibir promociones

Decide si el negocio puede enviarte mensajes promocionales desde PF. (PuntosFieles, 2026).

[Abrir la pantalla de esta tarea](/preferencias-de-mensajes/)

## Antes de empezar

Abre tu sesión de cliente en el negocio correcto. El permiso de promociones es diferente del código temporal necesario para entrar.

## Paso a paso

1. En tu tarjeta, pulsa **Elegir si quiero recibir promociones**.
2. Revisa el negocio y la preferencia actual.
3. Marca o desmarca **Quiero recibir promociones y recordatorios de este negocio.** y pulsa **Guardar preferencia**. Si llegaste desde un enlace de baja, confirma **Dejar de recibir promociones**.
4. Comprueba el mensaje de confirmación antes de cerrar.

## Qué debe pasar

La preferencia guardada se utiliza para comprobar el permiso de mensajes promocionales. Darse de baja no revierte puntos ya abonados ni retira un mensaje que el proveedor ya aceptó.

## Si algo no funciona

**La preferencia no carga:** vuelve a entrar desde el enlace del negocio. **Sigues recibiendo un mensaje anterior:** puede haber salido antes de la baja; informa al negocio con la fecha sin enviar códigos de acceso.
