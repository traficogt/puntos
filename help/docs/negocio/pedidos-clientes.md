# Dar seguimiento a lo que piden los clientes

Revisa solicitudes explícitas y registra un siguiente paso para el equipo. (PuntosFieles, 2026).

[Abrir la pantalla de esta tarea](/negocio/#pedidos-de-clientes)

## Antes de empezar

Necesitas pedidos u observaciones registrados. Estos datos no son compras garantizadas, ventas perdidas ni una muestra representativa del mercado.

## Paso a paso

1. Abre **Pedidos de clientes**. Filtra **Mostrar temas** por **Por revisar**, **En revisión**, **Planificado**, **Disponible** o **No previsto**.
2. Pulsa **Actualizar** y abre **Revisar** en el tema que atenderás.
3. Lee las solicitudes y distingue **Miembros únicos** de **Observaciones del equipo**.
4. Elige **Estado después de revisar**, escribe **Nota interna de seguimiento** y, si corresponde, **Volver a revisar (opcional)**. Pulsa **Guardar seguimiento**. La nota y la fecha no envían mensajes al cliente.
5. Vuelve a la lista para comprobar el estado guardado.

## Qué debe pasar

El tema conserva un seguimiento visible para el negocio. Un pedido expresa interés; no reserva un producto ni crea una orden de venta.

## Si algo no funciona

**Varias observaciones del mismo tema:** no las sumes automáticamente como personas distintas. **No hay evidencia suficiente:** deja el tema en revisión y documenta lo que falta. **El cliente espera una compra o entrega:** confirma fuera de este registro las condiciones comerciales.
