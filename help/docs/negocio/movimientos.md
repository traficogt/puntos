# Buscar y explicar un movimiento

Revisa qué quedó registrado en una compra, canje, reversión o ajuste de puntos. (PuntosFieles, 2026).

[Abrir la pantalla de esta tarea](/negocio/#movimientos)

## Antes de empezar

Ten la fecha, cliente o identificador del movimiento. Para buscar por ID, usa el identificador completo.

## Paso a paso

1. Abre **Movimientos** y pulsa **Actualizar historial**.
2. Filtra por **Tipo de movimiento** y **Origen de la actividad** si necesitas reducir la lista.
3. Pulsa **Explicar** junto al movimiento. Para uno antiguo, pega **ID del movimiento** y usa **Buscar movimiento**.
4. Lee el detalle para separar el importe, puntos registrados, estado y evidencia disponible.
5. Si el problema es un intento rechazado, usa **Explicar intentos de canje rechazados**.

## Qué debe pasar

El detalle muestra el registro y su explicación sin modificar saldos. Un intento de canje rechazado no equivale a un débito confirmado.

## Si algo no funciona

**No encuentras el ID:** comprueba que sea un identificador completo de movimiento y no el código corto de canje; para códigos usa **Canjes y caja**. **Falta evidencia histórica:** conserva la incertidumbre y revisa la caja o el caso correspondiente antes de ajustar puntos.
