# Pausar una recompensa y aprobar alternativas

Conserva las condiciones protegidas del cliente cuando cambia el programa o falta un premio. (PuntosFieles, 2026).

[Abrir la pantalla de esta tarea](/negocio/#promesas)

## Antes de empezar

Revisa las existencias y el costo de las alternativas. La protección conserva condiciones registradas desde que está activa; no inventa condiciones históricas que nunca se guardaron.

## Paso a paso

1. Abre **Promesas de recompensa** y revisa **Ciclos protegidos** por recompensa.
2. Pulsa **Configurar** en el beneficio correspondiente.
3. Revisa **Se puede entregar esta recompensa**. Si no está disponible, pausa su entrega.
4. Elige **Alternativas aprobadas** que puedas entregar y pulsa **Guardar disponibilidad**.
5. Explica al equipo que el cliente debe aceptar la alternativa y consulta después **Entregas registradas**.

## Qué debe pasar

Pausar una entrega no borra la promesa. Cuando el cliente acepta una alternativa aprobada, se mantiene el precio original en puntos y se registra el artículo realmente entregado. El primer canje con puntos cierra el ciclo protegido.

## Si algo no funciona

**Cliente con pendientes:** el progreso puede estar protegido, pero los pendientes siguen sujetos a liberación. **No hay alternativa adecuada:** conserva el caso y decide con el cliente; no registres aceptación por él. **Se necesita extensión:** atiéndela en el caso con autorización.
