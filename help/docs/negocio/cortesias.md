# Autorizar cortesías para el equipo

Aprueba un beneficio concreto, una persona y un presupuesto antes de emitir cortesías. (PuntosFieles, 2026).

[Abrir la pantalla de esta tarea](/negocio/#cortesias)

## Antes de empezar

Necesitas personal activo y una recompensa con costo conocido. Revisa cuánto puedes comprometer durante el turno; una cortesía no permite puntos libres.

## Paso a paso

1. Abre **Cortesías del equipo** y pulsa **Autorizar cortesía**.
2. Completa **Nombre para el cliente**, **Persona autorizada**, **Sucursal** y **Recompensa aprobada**.
3. Revisa unidades totales, límite de costo, presupuesto, **Tiempo para emitir** y **Plazo del cliente para canjear**.
4. Puedes usar **Usar prueba de hasta 5 unidades** como base, y ajustar los límites. Pulsa **Guardar autorización**.
5. Consulta **Actualizar resultados** e **Historial de cortesías** para distinguir emitidas, entregadas, vencidas y pendientes.

## Qué debe pasar

Cada emisión reserva el límite de costo de una unidad. Emitir no reserva existencias y entregar se confirma por separado. Revocar detiene nuevas emisiones, pero conserva beneficios ya emitidos.

## Si algo no funciona

**No alcanza para una unidad:** ajusta el presupuesto o el beneficio, sin ocultar el costo. **Una cortesía venció:** no repone automáticamente el compromiso reservado. **Costo parcial:** los importes desconocidos quedan fuera del costo estimado; los resultados no prueban retorno de inversión.
