# Buscar un cliente y corregir su nombre

Encuentra la cuenta por nombre o teléfono y consulta su saldo antes de atender una duda. (PuntosFieles, 2026).

## Antes de empezar

Ingresa como dueño. El teléfono identifica la cuenta; este formulario corrige el nombre y no transfiere puntos entre teléfonos.

## Paso a paso

1. Abre **Clientes**. Escribe **Buscar por nombre o teléfono** y pulsa **Buscar**.
2. Abre el nombre del cliente. Revisa **Puntos disponibles**, **Puntos pendientes** y **Última visita**.
3. Para una corrección, cambia **Nombre del cliente** y pulsa **Guardar nombre**.
4. Comprueba **Nombre actualizado**. Usa **Volver al directorio** para continuar.
5. Si tu plan lo permite, **Exportar CSV (hasta 5,000)** descarga el directorio; guarda el archivo únicamente donde corresponda para el trabajo del negocio.

## Qué debe pasar

El perfil conserva el nombre corregido sin cambiar el teléfono ni los saldos. El directorio tiene paginación; usa **Anterior** y **Siguiente** para recorrerlo.

## Si algo no funciona

**No encuentras la cuenta:** busca por teléfono y usa **Limpiar búsqueda** antes de concluir que no existe. **Otro usuario cambió el perfil:** utiliza **Volver a cargar perfil** y revisa la nueva versión. **Debes corregir un teléfono o un saldo:** consulta al responsable o soporte; este formulario no hace esos cambios.
