# Agregar una sucursal

Registra una nueva ubicación y después asigna el personal correspondiente. (PuntosFieles, 2026).

[Abrir la pantalla de esta tarea](/negocio/#sucursales)

## Antes de empezar

Ingresa como dueño y comprueba que tu plan incluye varias sucursales. Revisa cuántas tienes y el límite mostrado.

## Paso a paso

1. Abre **Sucursales** y pulsa **Agregar sucursal**.
2. Escribe **Nombre de la sucursal** y **Dirección**.
3. Completa **Código de sucursal (opcional)** si necesitas uno determinado. Si lo dejas vacío se crea automáticamente.
4. Pulsa **Crear sucursal** y comprueba **Sucursal creada**.
5. Usa **Asignar equipo a sucursales** para revisar cuentas. **Configurar ubicaciones de la tarjeta** permite revisar las coordenadas de Wallet por separado.

## Qué debe pasar

La ubicación aparece en la lista con dirección y código. Crear una sucursal no configura automáticamente una integración de caja ni una ubicación de Wallet.

## Si algo no funciona

**Llegaste al límite:** revisa tu plan antes de agregar otra. **Nombre o código inválido:** el nombre necesita al menos dos caracteres y un código escrito necesita al menos tres. **No puedes editar una dirección desde la lista:** esa vista permite consultar y agregar; pide ayuda para una corrección que no tenga un control disponible.
