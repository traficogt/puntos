# Revisar canjes y su registro en caja

Conecta el código PF de una recompensa con la evidencia de entrega del POS. (PuntosFieles, 2026).

[Abrir la pantalla de esta tarea](/negocio/#canjes)

## Antes de empezar

Necesitas acceso al panel y el código o recibo que investigarás. Un canje en PF confirma puntos; el estado de caja se comprueba por separado.

## Paso a paso

1. Abre **Canjes y caja**. Elige **Estado en caja** y pulsa **Actualizar canjes**.
2. Para un canje concreto, escribe el código completo o sus primeros caracteres en **Buscar por código PF** y pulsa **Buscar canje**.
3. Pulsa **Revisar canje** y compara la recompensa, sucursal, puntos y fecha con el recibo.
4. Registra la comprobación o revisión usando las opciones del detalle, después de verificar la evidencia.
5. Si el producto no se entregó o hay una devolución, revisa el caso relacionado antes de corregir puntos.

## Qué debe pasar

El historial distingue pendiente, registrado, requiere revisión, revisado, no corresponde e histórico sin evidencia. La declaración del equipo no prueba por sí sola las existencias físicas del POS.

## Si algo no funciona

**Histórico sin evidencia:** no significa que se entregó ni que faltó la entrega; requiere un comprobante adicional. **Puntos restituidos:** revisa el caso para no volver a corregirlos. **Referencia repetida o respuesta incierta:** actualiza y consulta el estado antes de crear otra comprobación.
