# Autorizar acciones con límites

Permite una acción específica por persona, sucursal y período. (PuntosFieles, 2026).

[Abrir la pantalla de esta tarea](/negocio/#equipo)

## Antes de empezar

Crea primero la cuenta del personal. Un rol de cajero no equivale a autorización ilimitada para restituir puntos, ampliar una promesa o activar una oferta.

## Paso a paso

1. Abre **Permisos del equipo** (pantalla **Equipo y turnos**; pulsa **Ver todas las herramientas** si el menú no la muestra) y pulsa **Autorizar persona**.
2. Elige **Acción autorizada**, **Persona del equipo** y **Alcance**.
3. Completa los límites que correspondan: puntos por acción, total, cantidad de acciones, frecuencia, costo y vigencia.
4. Revisa todos los límites juntos y pulsa **Guardar autorización**.
5. Consulta **Usos registrados**. Si debe terminar antes, utiliza **Revocar** en la autorización correcta.

## Qué debe pasar

PF comprueba los límites antes de cada uso. La autorización vigente no elimina los controles de saldo, evidencia, sucursal o disponibilidad.

## Si algo no funciona

**No aparece la persona:** debe ser una cuenta activa y elegible para la acción. **Se rechaza una operación dentro del límite de puntos:** revisa también cantidad, frecuencia, costo y vencimiento. **Revocaste la autorización:** se detienen nuevos usos; el historial no se borra.
