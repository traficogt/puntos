# Pedir ayuda con la información correcta

Envía una descripción que permita encontrar la operación sin compartir credenciales. (PuntosFieles, 2026).

[Abrir la pantalla de esta tarea](/soporte)

## Antes de empezar

Para puntos, recompensas, existencias o condiciones, consulta primero al negocio. PF puede ayudar con el funcionamiento técnico del sistema.

## Paso a paso

1. Escribe qué intentabas hacer y qué esperabas que ocurriera. Indica si eres cliente, personal o dueño.
2. Incluye el nombre de la pantalla, fecha, hora y zona horaria; agrega el texto exacto del error. No pegues direcciones que contengan códigos o enlaces privados.
3. Si hay una operación, conserva su código PF, referencia de recibo o identificador de caso. Oculta datos personales innecesarios en las capturas.
4. Consulta **Estado del servicio** si el problema afecta a varias personas.
5. Abre [Soporte](/soporte). Completa **Tu nombre**, **Correo de contacto**, **Categoría** y **Descripción**. El negocio y sucursal son opcionales.
6. Si adjuntas una captura, oculta primero cualquier dato sensible. Se acepta una imagen PNG, JPEG o WebP de hasta 600 KB y 4096 píxeles por lado. La captura se guarda de forma privada y vence a los 90 días.
7. Las opciones de vincular tu sesión e incluir datos básicos del navegador son voluntarias. Usa **Revisar los datos de diagnóstico** antes de incluirlos.
8. Pulsa **Enviar reporte**. Guarda la referencia y el **enlace privado de seguimiento** que aparecen al confirmarse la recepción.

## Qué debe pasar

El reporte queda guardado y puedes abrir tu enlace privado para consultar las respuestas. No se envía una confirmación automática por correo. La referencia por sí sola no permite abrir el caso.

## Consultar o responder

Abre el enlace que guardaste, o entra en **Ya tengo un reporte** y pégalo en **Enlace privado de seguimiento**. Pulsa **Consultar caso**. Puedes leer las respuestas públicas y enviar información adicional desde esa pantalla. Quien tenga el enlace puede leer y responder: no lo publiques ni lo compartas con otras personas.

## Si algo no funciona

**No incluyas contraseñas, códigos MFA, códigos de acceso por teléfono, tokens QR ni claves de integración.** Si se interrumpe el envío, deja abierta la página y vuelve a intentar con el mismo formulario: PF intenta recuperar la recepción anterior sin duplicarla. Si perdiste el enlace o la página no abre, escribe a [soporte@puntosfieles.com](mailto:soporte@puntosfieles.com). No hay recuperación automática del enlace. Para una recompensa pendiente, conserva el caso del negocio además del contacto técnico.
