# Pedir ayuda con la información correcta

Envía una descripción que permita encontrar la operación sin compartir credenciales. (PuntosFieles, 2026).

[Abrir la pantalla de esta tarea](/soporte)

## Antes de empezar

Para puntos, recompensas, existencias o condiciones, consulta primero al negocio. PF puede ayudar con el funcionamiento técnico del sistema.

## Paso a paso

1. Escribe qué intentabas hacer y qué esperabas que ocurriera. Indica si eres cliente, personal o dueño.
2. Incluye la dirección de la pantalla, fecha, hora y zona horaria; agrega el texto exacto del error.
3. Si hay una operación, conserva su código PF, referencia de recibo o identificador de caso. Oculta datos personales innecesarios en las capturas.
4. Consulta **Estado del servicio** si el problema afecta a varias personas.
5. Abre **Contactar a PF** y utiliza el canal o formulario disponible. Conserva la referencia o confirmación recibida.

## Qué debe pasar

El reporte permite seguir una situación concreta. Solo considera enviado el mensaje cuando el canal confirme su recepción; redactarlo o abrir un correo no demuestra que llegó.

## Si algo no funciona

**No incluyas contraseñas, códigos MFA, códigos de acceso por teléfono, tokens QR ni claves de integración.** Si no hay confirmación, revisa el canal antes de enviar otro reporte igual. Para una recompensa pendiente, conserva el caso del negocio además del contacto técnico.
