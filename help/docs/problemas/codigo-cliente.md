# El código de ingreso no llega

Comprueba el teléfono y las indicaciones de entrega antes de pedir otro código. (PuntosFieles, 2026).

[Abrir la pantalla de esta tarea](/mi-tarjeta/)

## Antes de empezar

Usa el enlace del negocio correcto y un teléfono al que tengas acceso. El código temporal es personal.

## Paso a paso

1. Revisa el número mostrado en **Revisa tu teléfono**. Si está mal, pulsa **Cambiar teléfono**.
2. Comprueba WhatsApp o SMS según lo que indique la pantalla y espera el plazo señalado.
3. Cuando se habilite, pulsa **Reenviar código** y usa el código nuevo.
4. Escribe los seis dígitos en **Código** y pulsa **Verificar y entrar**; si estás creando tu tarjeta, el botón dice **Verificar y crear tarjeta**.
5. Si sigue sin llegar, informa al negocio de la hora, el canal indicado y el mensaje de error.

## Qué debe pasar

La pantalla confirma la verificación y permite abrir tu tarjeta. Solicitar un código no prueba que el proveedor lo haya entregado.

## Si algo no funciona

**Código inválido o vencido:** solicita uno nuevo cuando se permita y utiliza el más reciente. **Botón bloqueado:** respeta el tiempo de espera y revisa el teléfono. **Aparece “Revisa el código de referido”:** al crear tu tarjeta, el código de quien te invitó debe tener 6 letras o números; corrígelo o deja vacío **Código de referido (opcional)**. Hasta entonces no se envía el código de ingreso. **Varios clientes afectados:** el dueño debe comprobar la mensajería. No publiques tu teléfono completo ni envíes códigos a soporte.
